# 🕌 Waktu Solat Malaysia — Windows 11 iOS Liquid Glass Screensaver

Screensaver untuk **Windows 11** yang memaparkan data waktu solat rasmi daripada **e-Solat JAKIM** berlatarkan koleksi gambar resolusi tinggi **Masjid-Masjid ikonik di Malaysia**, dengan reka bentuk antaramuka **iOS Liquid Glass**.

## ✨ Ciri-Ciri Utama
- **Reka Bentuk iOS Liquid Glass**: Kesan pembiasan kaca cecair (*SVG optical refraction*), kabur latar belakang tepu (*backdrop blur*), pantulan cahaya spekular, dan kesan paralaks 3D.
- **Data Rasmi e-Solat JAKIM**:
  - Memaparkan waktu **Imsak, Subuh, Syuruk, Dhuha, Zohor, Asar, Maghrib, dan Isyak**.
  - Kiraan detik (*countdown*) secara langsung ke waktu solat seterusnya beserta bar kemajuan.
  - Menyokong semua **Zon Waktu Solat JAKIM** di seluruh Malaysia (Semenanjung, Sabah, Sarawak & Wilayah Persekutuan).
  - Memaparkan tarikh **Hijri** dan arah **Kiblat**.
- **8 Wallpaper Masjid Ikonik Malaysia**:
  1. Masjid Putra, Putrajaya
  2. Masjid Selat Melaka, Melaka
  3. Masjid Kristal, Kuala Terengganu
  4. Masjid Wilayah Persekutuan, Kuala Lumpur
  5. Masjid Sultan Salahuddin Abdul Aziz Shah (Masjid Biru), Shah Alam
  6. Masjid Ubudiah Diraja, Kuala Kangsar
  7. Masjid Bandaraya Kota Kinabalu, Sabah
  8. Masjid Negara Malaysia, Kuala Lumpur
- **Sokongan Penuh `.scr` Windows 11**:
  - Boleh dipasang terus sebagai Screensaver Windows 11 (`/s`, `/c`, `/p`).

## 🚀 Cara Penggunaan
1. **Pratonton Interaktif**: Klik dua kali pada `Preview-Screensaver.bat` atau buka `index.html`.
   - Tekan `Space` untuk mengunci/membuka kunci **Mod Interaktif**.
   - Gunakan kekunci anak panah `◀` / `▶` untuk menukar gambar masjid.
   - Tekan `Esc` untuk keluar.
2. **Pasang Sebagai Screensaver Windows 11**: Klik dua kali pada `Install-Screensaver.bat`.
